# MPLADS Data Dictionary

Generated by `python -m mplads_audit.export_package` — every column of every exported file appears here; the export fails if one does not.

`temporal_availability` is the leakage control:

- `recommendation_time` — known when the work is recommended. **Safe to train on.**
- `post_recommendation` — known later but before completion.
- `post_completion` — only exists once the work finished. **Leaks** if used to predict completion.
- `as_of_extract` — depends on when the data was pulled (e.g. censored durations).
- `model_output` — produced by our own models; never an input to themselves.
- `static` — constants and provenance.
